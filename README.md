# Mooohla 🐄

App para repartir gastos entre amigos. Nació para una despedida de soltero
y quedó para todas las salidas que vengan.

El nombre mezcla *moola* (plata, en inglés) con el *muuu* de la vaca:
hacemos la vaquita.

## Qué hace

- Cada uno anota lo que pagó y entre quiénes se reparte.
- Muestra el total, el gasto por categoría y el saldo de cada uno.
- Calcula **quién le paga a quién** con la menor cantidad de transferencias.
- Lo que carga uno lo ven todos al instante.
- Se instala en el celular como una app y **funciona sin señal**.
- Cualquiera puede mirar, pero **solo el grupo puede editar**.
